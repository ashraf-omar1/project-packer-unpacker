Pack Project — تجميع

  • ✅ يقرأ جميع ملفات المشروع تلقائياً

1

احفظ السكريبت في مجلد مشروعك

ضع ملف project_tool.py في الجذر الرئيسي لمشروعك (Root Directory)، بجوار ملفات مثل package.json أو requirements.txt.

2

تأكد من وجود Python 3.6+

الأداة تعمل بدون أي مكتبات خارجية — تستخدم فقط os, sys, pathlib, datetime. تحقق بكتابة: python --version

3

شغّل الأداة

افتح Terminal في مجلد المشروع واكتب:

python project_tool.py
4

اختر العملية المطلوبة

ستظهر قائمة تفاعلية. اضغط 1 للتجميع أو 2 للتفكيك، ثم اضغط Enter.

5

عدّل الملف النصي وأعد البناء

بعد التجميع، يمكنك فتح full_project_code.txt بأي محرر نصوص، تعديل الكود، ثم تشغيل الخيار 2 لإعادة بناء المشروع بالتعديلات الجديدة.
